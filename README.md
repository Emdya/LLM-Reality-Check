# LLM-Reality-Check
Hackathon Project for SpurHacks, focused on reducing the number of "AI hallucinations" that occur in Large Language Models
## Explanation of this Addition
For each response from the LLM:

### 1.Retrieve external trusted facts dynamically (Wikipedia/Wikidata). ###

### 2. Compare the response to these facts using semantic similarity or even exact fact checking. ###

### 3. Use these results to validate or refute the original LLM response. ###
